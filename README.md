# 🎓 智能教育 Agent

> 智能教育Agent提供个性化的学习辅导服务，通过知识图谱和用户画像实现因材施教，让每个学生都能获得定制化的学习体验。


---

## 核心功能

| 功能模块 | 描述 |
|----------|------|
| 🤔 智能答疑 | 多学科问题解答，支持逐步推导讲解 |
| 🗺️ 学习计划 | 个性化学习路径规划，自动调整进度 |
| 📖 知识点讲解 | 图文并茂的交互式讲解，多维度解析 |
| ✏️ 习题生成 | 智能选题、难度自适配、变式训练 |

---

## 技术架构

系统由以下四大核心技术模块构成：

**1. RAG 检索增强生成**
从结构化知识库中检索相关内容，结合大语言模型生成高质量回答，确保内容准确性与专业性。

**2. 用户画像系统**
建立学习者能力模型，持续追踪各知识点的掌握度，动态识别强项与薄弱环节，为个性化推荐提供数据基础。

**3. 自适应学习引擎**
根据学生的实时学习表现，动态调整教学内容的难度与节奏，实现"跳一跳够得着"的最佳学习区间。

**4. 知识图谱**
构建学科知识点之间的关联关系网络，支持前置知识依赖分析与学习路径的智能规划。
